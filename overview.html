Modeling Near-future Westtown Solar Array Generation Through Predictive Machine Learning

Introduction

This research successfully combined weather, astronomical, and solar array datasets to train a sequential machine learning (ML) model that can reliably predict near-future solar array generation given exclusively forecasted inputs.

Model Performance

The trained architecture yielded an R² of 0.90, a Mean Absolute Error (MAE) of 12.04 kWh, and a Root Mean Square Error (RMSE) of 31.55 kWh (3.96%).

Primary Data Sources

  • Westtown Solar Array (1100060-Generation Inverter data)
  • Open-Meteo Weather Archive (Temperature, Cloud Cover, and Solar Inputs)
  • pvlib.solarposition Library (Time and Astronomical Inputs)

Future Applications

Downstream applications of these predictive models could implement optimizing EV charging, community-level battery storage management, and state-scale full-grid prediction models.
