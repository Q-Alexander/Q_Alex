Predictive Solar Generation


Using machine learning to predict near-future solar generation

Primary Architecture Elements

The Keras ML module is a simplified interface for ML model development that accommodates any sequential architecture of neural network layers. Layers are defined by their ML sequence position and by neuron count, with each neuron having a particular weight assigned through training. Two "hidden" or intermediate layers of dense neurons were sequenced, the first with a ~3:1 neuron to input ratio (biased towards the nearest power of two), the second hidden layer reducing the neuron count by a factor of 2.

Secondary Architecture Elements

Noise was added to each epoch through Dropout layers to prevent overfitting to training data. 1D Convolutional (Conv1D) layers were implemented to recognize variable dependencies within the input dataset, and Batch Normalization layers standardized each neuron's output between layers to stabilize the training process.

Learning Optimization

The loss function—the variable which was minimized throughout training—measured the predictive accuracy of the model. To efficiently reach the minimum loss during training, ReduceLROnPlateau was used to reduce the expected learning rate if, after consecutive epochs, the loss value did not decrease. The EarlyStopping function prevented the model from pursuing further epochs without meaningful loss function minimization. The final model trained, for example, terminated training after 93 of its prescribed 100 epochs.
